# Voicebox 音色索引

```dataview
TABLE WITHOUT ID
  file.link AS "档案",
  voice_type AS "类型",
  engine AS "引擎",
  voice AS "音色",
  use_case AS "用途",
  status AS "状态"
FROM "voice-profiles"
WHERE type = "voice-profile"
SORT file.name ASC
```

事实型历史讲解默认使用 `personality: false`。
