## 文博项目

使用 [[templates/文博图片项目模板|文博图片项目模板]] 创建新项目。

```dataview
TABLE WITHOUT ID
  file.link AS "项目",
  object_type AS "对象类型",
  period AS "年代",
  status AS "状态",
  verification AS "核验",
  audio_status AS "音频"
FROM "projects"
WHERE type = "cultural-project"
SORT file.mtime DESC
```
