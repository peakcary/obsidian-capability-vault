# 执行记录索引

```dataview
TABLE WITHOUT ID
  file.link AS "执行记录",
  date AS "日期",
  capability AS "能力",
  result AS "结果",
  reusable AS "可复用",
  validation AS "验证"
FROM "runs"
WHERE type = "run"
SORT date DESC
```
