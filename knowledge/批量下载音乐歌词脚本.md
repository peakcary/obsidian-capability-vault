# 批量下载音乐歌词脚本

## 概述

给定一个音乐文件夹，自动识别文件名中的歌手和歌名，依次从**网易云 → QQ音乐 → 酷狗**三个数据源下载 `.lrc` 格式歌词，保存为同名文件。

## 脚本位置

```
/Users/peakom/Downloads/download_lyrics.py
```

**附件：** [[download_lyrics.py]]

## 用法

```bash
# 使用默认目录
python3 /Users/peakom/Downloads/download_lyrics.py

# 指定任意音乐文件夹
python3 /Users/peakom/Downloads/download_lyrics.py /path/to/music
```

## 核心逻辑

### 文件名解析规则

文件名格式为 `歌手-歌名.wav`，脚本自动拆分：

```
beyond-光辉岁月.wav  →  artist=beyond  title=光辉岁月
周杰伦-青花瓷.wav    →  artist=周杰伦  title=青花瓷
```

括号注释（如 `(live)` `(dj版)` `[粤语]`）会在搜索前自动去除。

### 多源互补策略

| 顺序 | 数据源 | 优点 |
|------|--------|------|
| 1 | 网易云音乐 | 华语最全，LRC 质量高 |
| 2 | QQ 音乐 | 华语覆盖广，互补网易云 |
| 3 | 酷狗音乐 | 老歌覆盖好，进一步兜底 |

找到即止，三源均失败才标记为失败。

### 容错机制

- 已存在 `.lrc` 文件自动跳过（可中断重跑）
- 每源最多重试 2 次
- 请求间隔 0.4 秒，防止被限速
- 失败歌曲记录到 `_lyrics_failed.txt`

## 支持的音频格式

`.wav` `.mp3` `.flac` `.m4a` `.ape` `.ogg` `.wma`

## API 接入方式

### 网易云音乐

```
搜索: GET https://music.163.com/api/search/get?s={keyword}&type=1&limit=5
歌词: GET https://music.163.com/api/song/lyric?id={song_id}&lv=1
Referer: https://music.163.com/
```

### QQ 音乐

```
搜索: GET https://c.y.qq.com/soso/fcgi-bin/client_search_cp?w={keyword}&format=json
歌词: GET https://c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg?songmid={songmid}&format=json
注意: 歌词内容为 base64 编码，需解码
Referer: https://y.qq.com/
```

### 酷狗音乐

```
搜索: GET http://mobilecdn.kugou.com/api/v3/search/song?keyword={keyword}&pagesize=5
歌词: GET http://krcs.kugou.com/lyric?id={hash}&client=pc&format=lrc
注意: 搜索返回 hash 字段，作为歌词接口的 id；歌词为 base64 编码
```

## 注意事项

- 上述 API 均为非官方接口，接口格式可能随时失效
- 如某源失效，注释掉 `SOURCES` 列表中对应项即可
- 纯工具类脚本，无需安装任何第三方依赖（仅用标准库）
