# 批量下载音乐歌词脚本

给定音乐文件夹，解析歌手、歌名，查询多个来源，**仅保存真实带时间轴的 UTF-8 LRC**。原有 CLI 参数保持兼容，不新增第三方依赖。

维护入口：`/Users/peakom/Downloads/download_lyrics.py`  
附件快照：[[assets/download_lyrics.py|download_lyrics.py]]  
离线测试：`/Users/peakom/Downloads/test_download_lyrics.py`  
验证证据：[[runs/2026-10-16-歌词下载脚本修复与验证]]  
复用能力：[[capabilities/批量匹配与下载LRC歌词]]

## 用法

```bash
# 默认按网易云 → QQ → 酷狗查询，LRC 保存在音频旁
python3 /Users/peakom/Downloads/download_lyrics.py /path/to/music

# 统一保存到指定目录（目录需要已存在）
python3 /Users/peakom/Downloads/download_lyrics.py /path/to/music --output /path/to/lyrics

# 仅启用 LRCLIB；是否需要代理取决于当前网络
python3 /Users/peakom/Downloads/download_lyrics.py /music --lrclib --no-cn

# 指定 HTTP 代理，也接受完整的 http://HOST:PORT 地址
python3 /Users/peakom/Downloads/download_lyrics.py /music --lrclib --no-cn --proxy 127.0.0.1:7890

# 启用 Musixmatch，要求密钥具备真实字幕接口权限
python3 /Users/peakom/Downloads/download_lyrics.py /music --musixmatch YOUR_API_KEY --no-cn

# 在 Downloads 目录运行离线测试，不会请求网络
cd /Users/peakom/Downloads
python3 -m unittest -v test_download_lyrics
```

| 参数 | 行为 |
| --- | --- |
| 位置参数 | 音乐文件夹，省略时沿用原脚本的默认目录 |
| `--output DIR` | 可选输出目录，默认保存到音频旁 |
| `--lrclib` | 将 LRCLIB 加在默认来源之后；并非只支持国外歌曲 |
| `--musixmatch KEY` | 启用 Musixmatch 真实字幕查询，不生成估算时间轴 |
| `--no-cn` | 禁用网易云、QQ、酷狗，需同时启用其他来源 |
| `--proxy HOST:PORT` | 为本次进程设置 HTTP(S) 代理，不接受 SOCKS 代理 |

显式指定代理会作用于本次进程的所有来源；未指定时由 urllib 按环境/系统配置处理。没有“LRCLIB 在国内必然无法直连”的保证；本机本次直连已成功。

## 解析、匹配与保存

- 支持 `.wav`、`.mp3`、`.flac`、`.m4a`、`.ape`、`.ogg`、`.wma`、`.aac`、`.aiff`，忽略扩展名大小写。
- 仅扫描当前目录的普通文件，不递归、不跟随音频符号链接、不把 `目录.mp3` 当作歌曲。
- 支持 `歌手-歌名.wav`、`歌手－歌名.wav`、`歌手—歌名.wav`、`歌手《歌名》.wav`，以及歌名含中文时的 `歌手 歌名.wav`。
- `Hotel California.mp3` 这类无明确分隔符的英文文件名整体视为歌名。
- **保留** `(Live)`、`(DJ版)`、`[粤语]` 等版本文字；不再为了提高命中率而删除版本信息。
- 歌名、指定歌手必须规范化后相符；合唱要求指定歌手全部出现，不直接取第一条搜索结果。歌手别名不一致时可能保守拒绝。
- 同一来源中，匹配结果没有有效时间轴时继续查找下一条匹配记录，再换来源。
- 无歌手时，只能按歌名匹配，仍可能存在同名异曲；未读取音频时长，不能保证时间轴与剪辑版完全一致。
- 输出为与音频同名的 `.lrc`；只验证有合法时间戳和非空文字的结果，不接受纯文本、仅元信息或空时间戳。
- 默认和指定输出目录共用同一保存逻辑。目标已存在（包括符号链接）即跳过；目标为空或无效也不会自动覆盖。
- 先在输出目录写完临时文件，再通过硬链接提交，避免留下半个 LRC 或覆盖并发生成的文件。**FAT/exFAT 和部分网络盘可能不支持此方式，会明确报保存失败。**

## 来源与边界

| 顺序 | 来源 | 接入与本次验证 |
| --- | --- | --- |
| 1 | 网易云 | 公开接口，非官方稳定性承诺；本次取得有效 LRC |
| 2 | QQ 音乐 | 兼容明文、HTML 实体与 Base64；本次取得有效 LRC |
| 3 | 酷狗 | 歌曲 hash → 歌词候选 id/accesskey → Base64 LRC；本次完整链路通过 |
| 可选 | LRCLIB | 官方公开 API，无需 API key；只读取 `syncedLyrics`，本次直连成功 |
| 可选 | Musixmatch | 官方 API，需要密钥及字幕权限；没有密钥，只有离线模拟测试通过 |

不对 Musixmatch 的当前免费配额、可返回比例或付费权限做未经核验的承诺。当前实现请求 `matcher.subtitle.get`、`subtitle_format=lrc`，接口拒绝、缺少真实字幕或受限时回退其他源，不将纯文本每秒一行包装成 LRC。

酷狗原 `mobilecdn.kugou.com` 搜索地址在本次 HTTPS 请求中出现证书域名不匹配；改用能够正常验证证书的 `mobileservice.kugou.com`，不关闭 TLS 验证。

## 网络、错误与重跑

- 网络请求之间至少间隔 0.4 秒；每次请求最多尝试 2 次。
- 429 限流等待 20 秒重试；5xx 或临时网络错误等待 2 秒重试；其他 HTTP 错误不重复请求。
- 单次超时 12 秒，响应最多 2 MiB；严格按 UTF-8 解码，不静默丢字节。
- 没有匹配结果或无有效 LRC 时直接换源，不重复进行相同的无效搜索。
- 输出来源错误信息；HTTP 错误不输出完整请求 URL，日志隐藏 Musixmatch 密钥。不在笔记和执行记录保存真实密钥。
- `_lyrics_failed.txt` 写入实际输出目录，记录原音频文件名；本次没有失败时清空已有的旧报告，避免将过时失败项当作现状。
- Ctrl+C 保留已完成文件，保存已知失败列表，并统计未处理数量；重跑会跳过已存在 LRC。
- 退出码：`0` 正常完成，`1` 存在失败或 I/O 错误，`2` 参数/目录错误，`130` 用户中断。
