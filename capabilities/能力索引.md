# 能力索引

```dataview
TABLE WITHOUT ID
  file.link AS "能力",
  domain AS "领域",
  status AS "成熟度",
  trigger_phrases AS "触发语句",
  tools AS "工具",
  success_count AS "成功次数",
  last_verified AS "最近验证"
FROM "capabilities"
WHERE type = "capability"
SORT domain ASC, file.name ASC
```
