# Wails应用增加无桌面依赖的NAS网页入口

## 范围与前提
适用于核心逻辑可与 GUI 生命周期分离的 Go/Wails 应用。须获授权访问代码和部署目标；用户通过本机交互提供 sudo 认证，不收集密码。

## 步骤
1. 确认目标 CPU 架构、容器权限、媒体目录及数据目录，先检查已有 HTTP 媒体服务和 Wails 绑定。
2. 用独立 build tag 隔离桌面入口及原生文件。合并已有平台约束，保持桌面回归。
3. 网页适配层只开放明确允许的方法；使用同源媒体地址、Range、受根目录约束的路径解析及身份认证。
4. 网页替代本地文件选择器，移除原生窗口控制；保留浏览器支持的交互。限制持久化写入数据目录，原始媒体只读。
5. 先用合成音频完成浏览器及核心测试，再交叉编译并在目标机器验证。需要离线构建时使用静态程序和公开 CA 证书制作 scratch 镜像。
6. 上传部署包，校验 Compose。若文件传输接口与 SSH 路径不一致，可用 SSH tar 通道，无需调整服务端权限。
7. 容器启动需要管理员认证时，先准备具体文件和命令，由用户本机执行；启动后继续验证真实容器、端口、数据和媒体服务。

## 当前验证边界
实现、桌面回归、浏览器、NAS 原生程序与实际容器均已验证。容器使用真实音乐完成播放、Range、歌词接口与移动端弹窗验证，并确认普通用户、只读媒体挂载和持久化曲库文件；尚未进行容器重启验收。

## 绿联客户端内嵌边界
本能力交付浏览器网页，不能把 Docker 桌面快捷方式视为客户端内嵌入口。要在绿联系统桌面内打开，需另行核验 UPK、inner、SDK 鉴权、媒体请求及开发者授权。参见 [[runs/2026-10-25-绿联内嵌播放器部署机制核验]] 和 [[sources/绿联官方内嵌应用与开发授权文档]]。
