# 绿联官方内嵌应用与开发授权文档

- [打开方式](https://developer.ugnas.com/doc/backend/application/open-type.html)：inner 为系统桌面窗口，tab 为浏览器标签页。
- [开发准备](https://developer.ugnas.com/doc/backend/quick-start/prepare.html)：自制应用测试需官方开发者授权；新固件需要应用中心整机授权操作。
- [原生应用](https://developer.ugnas.com/doc/backend/quick-start/develop.html)：前端静态文件与原生后端分开打包，通过 ugcli 在 Linux 生成可安装 UPK。
- [运行环境](https://developer.ugnas.com/doc/backend/application/runtime-environment.html)：独立运行用户和受限文件视图；数据用 UGAPP_DATA_DIR；音乐等共享目录需主动授权并由 shared 软链暴露。
- [登录认证](https://developer.ugnas.com/doc/backend/system-capabilities/login-auth.html)：inner、代理前缀、SDK token 与系统网关共同构成认证通路。
- [媒体管理](https://developer.ugnas.com/doc/frontend/ugos-core/mediaCenter.html)：只支持宿主直属窗口的媒体，不支持多层嵌套 iframe。

## 验证边界
官方文档已核实，且目标 NAS 已安装应用配置中的 inner/tab 区别与文档一致。未验证自制原生 UPK 安装，未验证 audio 原生请求如何穿过 token 网关。
